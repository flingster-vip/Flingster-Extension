# Flingster Member Access: Quick Install

## 1. Download
- Download the latest `.zip` from the releases page and unzip it.

## 2. Install in Chrome
1. Go to `chrome://extensions` and turn on **Developer Mode** (top right).
2. Click **Load unpacked** and select the unzipped folder.
3. Pin the extension from the 🧩 puzzle icon.

## 3. Activate
1. Click the extension icon and enter your access password.
2. Click **Authenticate**.
3. A green ✅ means you're logged in.

**No password?** Book a slot at https://flingslots.in

## Troubleshooting
| Message | Fix |
|---|---|
| Invalid password | Check for typos (case-sensitive) |
| Token has expired | Book a new slot |
| Access not yet active | Check your booking's start time |
| Could not reach data store | Check your internet connection |
| Not in toolbar | Pin it via the 🧩 icon |

## Notes
- **Remember password** saves it locally on your device.
- **Clear Session & Cookie** logs you out.
- The extension only works on flingster.com.
